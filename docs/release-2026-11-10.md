## Ownership

Core owns contracts and validation; React owns screens and record synchronization; device owns runtime composition and routing; theme owns styles and tokens; editor owns controlled authoring and preview-selection events. Hosts retain persistence, permissions, transport, publication and their surrounding layout. No host API or Python dependency was changed by this package release preparation.

Device now initializes the portable mailbox from session Email screen state and accepts `selectedEmailId` / `onSelectedEmailChange`. A custom `renderMailbox` remains available for provider-specific integrations. DeliveryPlus can use the default composition instead of duplicating it.

## Release order and references

Publish core and theme before React; publish React before device and editor. Device requires exact core 0.7.2, React 0.21.2 and theme 0.13.3. React requires core 0.7.2 and optionally theme ^0.13.3. Editor peers and development dependencies use this same coordinated set.

No registry integrity or lockfile entry may be invented. Until new artifacts are published, existing host registry pins remain the last real published versions; explicitly selected local review artifacts are a separate authority. Finalize registry locks and consumer pins only from the published artifact metadata. Do not publish or deploy merely by pushing this branch.
